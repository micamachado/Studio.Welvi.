# Studio WELVI

Site vitrine de Studio WELVI, studio web spécialisé dans les professionnels du bien-être.

## Mise en ligne sur GitHub Pages

1. Importez tous les fichiers de ce dossier dans un dépôt GitHub.
2. Dans **Settings → Pages**, choisissez **Deploy from a branch**.
3. Sélectionnez la branche `main` et le dossier `/ (root)`.

Le site est statique, responsive et ne nécessite aucune installation.

## Avant la publication

- Remplacez `bonjour@welvi.lu` si nécessaire.
- Ajoutez l'URL définitive du site dans les balises `canonical` et Open Graph de `index.html`.
- Reliez le bouton de prise de rendez-vous à votre agenda si vous utilisez Calendly, Cal.com ou un autre service.
